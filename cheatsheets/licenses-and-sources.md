# Cheatsheet · Licenses & sources

Full chapter: [08](../chapters/08-free-and-legal-sources.md). Rule of thumb: **license is per-asset, not per-site.** Links last checked **26 August 2026** (UTC+7).

## Licenses in one line each

| License | Commercial? | Credit? | Note |
|---|---|---|---|
| CC0 | ✅ | optional | do anything |
| CC-BY | ✅ | required | credit in your credits screen |
| CC-BY-SA | ✅ | required | derivatives of the asset share the license |
| CC-BY-NC | ❌ | required | **Shadertoy's default — learn, don't lift** |
| MIT / OFL | ✅ | keep license text | code / fonts |
