Sprite basics — load, attach, place

This demo even generates its image from code (two loops, one colour decision per pixel), so you can see there's no magic hiding in an asset file. Then it places that image several times with different position, scale, and alpha (transparency).

The same 16×16 image, placed four ways. "Moving a sprite" = changing those x, y numbers. That's the whole secret.

Try tweaking: the eye positions (lines with inEye) · the body colour · the crowd loop count from 5 to 12 · the Math.sin(i) * 18 wobble to 50. Every change is one number, and Reset always brings the original back.

In Godot: this is Sprite2D.new() + add_child() (see the sprite_basics scene in the repo's Godot project). In Unity: AddComponent<SpriteRenderer>() + transform.position. In Unreal: a UMG Image widget or PaperSprite. Same recipe, different accents — chapter 02 shows all four.
