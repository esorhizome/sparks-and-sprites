Flame — rising, shrinking, fading, adding

Fire = particles that rise, shrink, fade from yellow to orange to nothing, wobble sideways, and use additive blending (overlaps get brighter, because fire is made of light). Each of those five words is one line below.

Soft, warm, and endlessly hypnotic — from ~35 lines with no images. Change the numbers and the fire changes species.

Try tweaking: rise speed rand(-90,-50) → rand(-30,-15) for lazy smoke-fire · the colour line: swap red/green for a blue-green ghost flame (r = 40*u, g = 180, b = 255) · wobble strength 18 → 60 for wind · spawn count 4 → 1 for a candle. Delete the "lighter" line and see how much additive blending was doing.

In Godot: the flame scene configures GPUParticles2D with these same choices, commented. In Unity: Particle System — Start Speed up, Lifetime 0.7, Color-over-Lifetime yellow→orange→transparent, Size-over-Lifetime shrinking, additive material. Retune each and you've made fire, not copied it. In Unreal: Niagara's Fountain template already contains every module named here — same retune. Chapter 06.
