# 10 · If you freeze up

*Fresh-start note: none needed. This chapter is for the days when even the fresh-start notes feel like a lot.*

---

For when this book — or any page of code — becomes a wall:

1. **Pick one entry.** Not the *right* one. Any one. The entries are deliberately independent, so "where do I even start" has no wrong answer.

2. **Run its smallest example unchanged.** Working code you didn't write is still working code *on your screen*, and your nervous system counts it. The [web demos](https://esorhizome.github.io/sparks-and-sprites/) exist so this step needs zero setup: open, press Run.

3. **Change one number.** A duration, a colour, a count. That is not a warm-up for real programming — it **is** real programming. It's what everyone senior is doing all day, just with more tabs open.

4. **Stop while it works.** Ending on a working state makes returning tomorrow easy; ending mid-bug makes returning hard. Stopping early-and-working is allowed and is, in fact, the professional move.

---

Everything in this book was once unknown to every person who now uses it casually. The distance between them and you is exposure and repetition — not category. And this book will still be here on the days memory isn't. That's what it's *for*: re-reading a definition for the fifth time isn't failing to learn — it's exactly how this material was always meant to be held. By the book, so it doesn't have to be held by you.
