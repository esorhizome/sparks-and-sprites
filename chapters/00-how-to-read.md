# 00 · How to read this book

*Reading time: three minutes. Prerequisites: none, and that stays true for every chapter.*

---

## The promises

**Every entry has the same shape.** *What it is → where it lives in each engine → the smallest working example → what usually goes wrong.* Once you've read one entry, you know how to read all of them. You never need to hold the whole book in your head — that's the book's job.

**No chapter assumes you remember another chapter.** Every technical word gets re-explained the moment it appears, every time, in every chapter. If you open chapter 06 cold after four months away, it will still make sense. Definitions repeat *on purpose* — repetition is how the words eventually become yours, and until then, they're always within arm's reach.

**Nothing here can break anything.** This is a map, not a machine. Skimming is reading. Forgetting is expected. Returning is the whole design.

**Show first, then tell.** Where a thing can be seen, a [live demo](https://esorhizome.github.io/sparks-and-sprites/) shows the code and the visual result side by side, and the code is editable in place. Seeing `code X → visual Y` once outperforms reading ten paragraphs about it.

## Why Web and Godot get demos, and Unity and Unreal get explanations

Web demos run in the thing you're already using (a browser). Godot demos are a 100 MB free download away, and each demo is one commented script. Unity and Unreal projects, by contrast, are gigabytes of installer and minutes of load time each — bundling them would turn a study book into a warehouse. So for those two, every chapter gives you the *equivalent code*, explains *why* it produces the same visual result, and ends with an invitation: **try it in your own project, and tweak the numbers as you prefer.** The ideas transfer one-to-one; only the spelling changes.

## How to use the demos

1. Open one. Press **Run** without changing anything. It works — you've established that.
2. Change **one number**. Press Run again. Watch what changed.
3. That loop — run, tweak one thing, run — is not a warm-up for real programming. It **is** real programming. It's what senior people are doing all day, with more tabs open.

## If a chapter ever feels like a wall

That's not a verdict on you; it's a signal to jump to [chapter 10](10-if-you-freeze-up.md), which exists precisely for that moment. It's two minutes long.
